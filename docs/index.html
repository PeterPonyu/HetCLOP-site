Calibration gains from added dispersion need not carry over to marker recovery in single-cell count decoders

Zeyu Fu · ORCID 0009-0001-8329-0108

Single-cell count decoders are often judged by how closely their samples match within-cell-type variance. The article compares dispersion choices at fixed predicted means on public GEO datasets and scores variance calibration, marker recovery, cell-type classification and end-to-end generation separately. This page links the code, result records and data behind it.

Archive and code

  • Archive, version 3.0.3: doi:10.5281/zenodo.23940846. It holds the code archive and the analysed corpus (counts, cell-type labels and splits) as two files.
  • All versions: doi:10.5281/zenodo.21524011 resolves to the latest one.
  • Code: github.com/PeterPonyu/HetCLOP-site. The tag v3.0.3 matches the code archive, apart from the files of this page.
  • Source data: the public GEO accessions listed in revisions/major-revision/manuscript/figs/dataset_table.csv.

Reproducing the results

git clone https://github.com/PeterPonyu/HetCLOP-site.git
cd HetCLOP-site
# download hetclop-corpus-3.0.3.tar from the archive and unpack it, then
python scripts/restore_corpus.py /path/to/hetclop-corpus-3.0.3
python revisions/major-revision/evidence/followup_macros.py
python revisions/major-revision/evidence/verify_followup_experiments.py

The README in the repository lists the requirements, the analyses that need the scGPT or Geneformer embeddings (recomputed from the public model weights) and the figure build.
